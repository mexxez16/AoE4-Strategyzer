# Fonts Directory

## Required Font Files

To use the Trajan Pro font, place the following files in this directory:

### Trajan Pro (Commercial Font)
- `TrajanPro-Regular.woff2`
- `TrajanPro-Regular.woff`
- `TrajanPro-Regular.ttf`
- `TrajanPro-Bold.woff2`
- `TrajanPro-Bold.woff`
- `TrajanPro-Bold.ttf`

**Note:** Trajan Pro is a commercial font by Adobe. You need to purchase a license from:
- Adobe Fonts
- MyFonts
- Or other authorized font distributors

### Alternative: Cinzel (Free Font)
If you don't have Trajan Pro, you can use Cinzel as a free alternative:

1. Download from Google Fonts: https://fonts.google.com/specimen/Cinzel
2. Place these files here:
   - `Cinzel-Regular.woff2`
   - `Cinzel-Regular.woff`
   - `Cinzel-Bold.woff2`
   - `Cinzel-Bold.woff`

## Font Format Priority
1. `.woff2` - Best compression, modern browsers
2. `.woff` - Good compression, wide support
3. `.ttf` - Fallback for older browsers

## Converting Fonts
If you only have .ttf or .otf files, you can convert them:
- Online: https://cloudconvert.com/ttf-to-woff2
- Tool: FontForge (free, open-source)
